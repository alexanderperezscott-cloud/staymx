# StayMX

StayMX es una plataforma web de alquiler de alojamientos en México diseñada para conectar a viajeros con propiedades únicas y a anfitriones que desean publicar sus espacios de forma sencilla.

## ¿Qué hace la página?

StayMX permite a los usuarios:

- Explorar alojamientos disponibles con una interfaz moderna y rápida.
- Buscar propiedades por nombre, ubicación y tipo de inmueble.
- Filtrar resultados por precio y categoría.
- Guardar alojamientos en favoritos para revisarlos después.
- Reservar o gestionar reservaciones desde la plataforma.
- Publicar propiedades como anfitrión mediante un formulario guiado.
- Ver ubicaciones de propiedades en un mapa interactivo.
- Chatear con el anfitrión o gestionar solicitudes de reserva.

## ¿Para qué sirve?

La idea de StayMX es facilitar el proceso de encontrar un lugar para hospedarse durante viajes, escapadas o estadías temporales, mientras también ayuda a los anfitriones a promocionar y administrar sus propiedades de una manera más simple y organizada.

Es una Single Page Application (SPA) enfocada en ofrecer una experiencia visual, rápida y cómoda tanto para huéspedes como para anfitriones.

## Características principales

- Diseño moderno con React y Tailwind CSS
- Autenticación de usuarios
- Gestión de favoritos
- Modo anfitrión para publicar propiedades
- Reservaciones y panel de gestión
- Integración con Supabase para almacenamiento y datos en tiempo real
- Mapa interactivo para visualizar ubicaciones

## Tecnologías utilizadas

- React 19
- Vite
- Tailwind CSS
- Supabase
- Mapbox
- React Hot Toast

## Cómo ejecutar el proyecto

1. Instala las dependencias:

   ```bash
   npm install
   ```

2. Inicia el proyecto en modo desarrollo:

   ```bash
   npm run dev
   ```

3. Abre la URL que aparece en la terminal para ver la aplicación.
