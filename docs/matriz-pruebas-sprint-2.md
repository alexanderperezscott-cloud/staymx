# Matriz de pruebas - StayMX

**Semana:** 5 - Implementacion SPA, Sprint 2 y pruebas  
**Producto:** StayMX  
**Tipo de prueba:** funcional, integracion y regresion manual en navegador  
**Criterio de registro:** marcar `Aprobado`, `Fallido` o `Bloqueado` y adjuntar evidencia (captura, consola o registro de Supabase).

## Datos de prueba

| Dato                    | Valor sugerido                                                                                                                                      |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| URL                     | `http://localhost:5173`                                                                                                                             |
| Usuario valido          | Cuenta de prueba confirmada en Supabase                                                                                                             |
| Usuario invalido        | Correo no registrado o contrasena incorrecta                                                                                                        |
| Busqueda con resultados | `Campeche`                                                                                                                                          |
| Busqueda sin resultados | `zzzz-no-existe`                                                                                                                                    |
| Categoria               | `Casa`                                                                                                                                              |
| Fechas validas          | Check-in manana y check-out cuatro dias despues                                                                                                     |
| Datos de alojamiento    | `Casa QA Sprint 2`, tipo `Casa`, precio `850`, direccion `Av. Prueba 123`, ciudad `Campeche`, estado `Campeche`, descripcion de prueba e imagen JPG |
